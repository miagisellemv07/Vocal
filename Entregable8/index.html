Estimación de afinidad profesional mediante factores de certeza

5 casos con factores de certeza

Modelo matemático: factores de certeza (CF)

Cuando dos evidencias distintas apoyan la misma carrera, sus factores positivos se combinan mediante:

CF_combinado = CF₁ + CF₂ × (1 − CF₁)

Para tres o más evidencias, el resultado anterior se combina con el siguiente factor. Se recomienda la carrera con el mayor CF acumulado.

Los valores son pesos ilustrativos del ejercicio. El porcentaje expresa un índice de certeza del modelo, no una probabilidad estadística validada de éxito profesional.

Tabla de evidencias y factores de certeza base

Se utilizan los vínculos directos entre intereses y carreras, y las habilidades que cada carrera requiere en nuestra base. Cada evidencia se cuenta una sola vez por carrera.

Resolución de los cinco casos

Caso 1: Tecnología y matemáticas

Hechos iniciales

interes_tecnologia = TRUE
habilidad_matematica = TRUE

Ingeniería recibe dos apoyos: tecnología (0.85) y matemáticas (0.80). 

CF_Ingenieria
= 0.85 + 0.80 × (1 − 0.85)
= 0.85 + 0.12
= 0.9700

Comparación: Ingeniería 0.9700; Administración 0.8000; Medicina, Diseño y Derecho 0.

Mayor afinidad INGENIERÍA 97.00% de certeza del modelo

Caso 2: Salud y análisis

Hechos iniciales

interes_salud = TRUE
capacidad_analisis = TRUE

Medicina recibe dos apoyos: salud (0.85) y análisis (0.75). 

CF_Medicina
= 0.85 + 0.75 × (1 − 0.85)
= 0.85 + 0.1125
= 0.9625

Comparación: Medicina 0.9625; Ingeniería y Derecho 0.7500; Administración y Diseño 0.

Mayor afinidad MEDICINA 96.25% de certeza del modelo

Caso 3: Negocios y liderazgo

Hechos iniciales

interes_negocios = TRUE
habilidad_liderazgo = TRUE

Administración recibe dos apoyos: negocios (0.85) y liderazgo (0.60). 

CF_Administracion
= 0.85 + 0.60 × (1 − 0.85)
= 0.85 + 0.09
= 0.9400

Comparación: Administración 0.9400; Ingeniería, Medicina, Diseño y Derecho 0.

Mayor afinidad ADMINISTRACIÓN 94.00% de certeza del modelo

Caso 4: Arte, creatividad y comunicación

Hechos iniciales

interes_arte = TRUE
habilidad_creatividad = TRUE
habilidad_comunicacion = TRUE

Diseño recibe tres apoyos: arte (0.85), creatividad (0.65) y comunicación (0.70). 

CF_parcial
= 0.85 + 0.65 × (1 − 0.85)
= 0.9475

CF_Diseno
= 0.9475 + 0.70 × (1 − 0.9475)
= 0.9475 + 0.03675
= 0.98425

Comparación: Diseño 0.98425; Medicina y Derecho 0.7000; Administración 0.6500; Ingeniería 0.

Mayor afinidad DISEÑO 98.43% de certeza del modelo

Caso 5: Educación y comunicación

Hechos iniciales

interes_educacion = TRUE
habilidad_comunicacion = TRUE

Derecho recibe dos apoyos según nuestra base: educación (0.85) y comunicación (0.70). 

CF_Derecho
= 0.85 + 0.70 × (1 − 0.85)
= 0.85 + 0.105
= 0.9550

Comparación: Derecho 0.9550; Medicina y Diseño 0.7000; Ingeniería y Administración 0.

Mayor afinidad DERECHO 95.50% de certeza del modelo
