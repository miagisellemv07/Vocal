ENTREGABLE 5

Juego de Inferencias (Cadenas Lógicas)

Demostración gráfica y deductiva de 5 cadenas de inferencia

¿Qué es una cadena de inferencia?

Una cadena de inferencia muestra el razonamiento paso a paso que sigue el sistema para llegar a una conclusión. En el encadenamiento hacia adelante, los hechos permiten activar reglas y obtener recomendaciones. En el encadenamiento hacia atrás, se parte de una recomendación posible y se buscan los hechos que permitirían respaldarla.

Las siguientes cinco cadenas utilizan encadenamiento hacia adelante y las reglas del entregable 4.

Diagrama: Cadena de Inferencia Vocacional (Caso 1)

Cadena 1: Ingeniería

Hechos

  • Le gusta la tecnología.
  • Tiene habilidad matemática.

↓ Activa Regla R1

SI interes_tecnologia = TRUE Y

habilidad_matematica = TRUE

ENTONCES recomendacion = Ingenieria

↓ Deduce la recomendación

Tecnología + Matemáticas ↓ Ingeniería
