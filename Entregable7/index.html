¿Qué significa razonamiento no-monótono?

Una recomendación inicial puede revisarse cuando aparece nueva información que contradice sus condiciones. El sistema retira la conclusión anterior y utiliza los hechos actuales para generar una nueva recomendación.

En estos casos, las recomendaciones son provisionales: una respuesta corregida reemplaza el valor anterior de la misma variable.

Las 5 excepciones vocacionales

Revisión de creencias

Excepción 1: Ingeniería → Diseño

Retractación

Regla general · R1

SI interes_tecnologia = TRUE
Y habilidad_matematica = TRUE
ENTONCES recomendacion = Ingenieria

Nueva evidencia

El estudiante aclara que no le interesa la tecnología; le interesan el arte y la creación visual. 

interes_tecnologia = FALSE
interes_arte = TRUE
habilidad_creatividad = TRUE

Justificación

R1 pierde una de sus condiciones. Las habilidades matemáticas se conservan, pero ya no sostienen esa recomendación mediante R1. Los nuevos hechos activan R7.

Conclusión retirada

RETRACTAR recomendacion = Ingenieria

Nueva conclusión · R7

SI interes_arte = TRUE
Y habilidad_creatividad = TRUE
ENTONCES recomendacion = Diseno
